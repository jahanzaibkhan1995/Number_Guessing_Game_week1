# 🎯 Number Guessing Game

A simple **C# console-based Number Guessing Game** created as part of my **Week 1 C# learning project**.

## 📌 Features

* Guess a number between 1 and 1000
* Maximum 5 attempts
* Displays whether the guess is correct or incorrect
* Option to restart the game
* Simple console interface

## 🛠️ Technologies

* C#
* .NET 10
* Visual Studio

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/jahanzaibkhan1995/Number_Guessing_Game_week1.git
```

Open the project in Visual Studio and run it, or use:

```bash
dotnet run
```
